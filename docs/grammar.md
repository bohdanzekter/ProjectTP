# Формальна специфікація мови SIPL

Специфікація відповідає БНФ мови SIPL

## 1. Лексика

- **Ключові слова (зарезервовані):** `begin`, `end`, `if`, `then`, `else`, `while`, `do`, `skip`.
- **Логічні оператори:** `∨` (або ASCII-аліас `or`), `¬` (або ASCII-аліас `not`). Зарезервовані.
- **Оператори та роздільники:** `:=`, `;`, `+`, `-`, `*`, `=`, `>`, `(`, `)`.
- **Ідентифікатори (`IDENT`):** `[a-zA-Z_][a-zA-Z0-9_]*`, що не збігаються із зарезервованими словами.
- **Цілі числа (`NUMBER`):** цілі числа (включно з від’ємними, напр. `-1`, `0`, `42`).
- **Пробільні символи та коментарі:** пробіли, табуляції, переноси рядків та однорядкові коментарі `// ...` ігноруються.

## 2. Пріоритет операцій та асоціативність

Усі бінарні операції є **лівоасоціативними**. Пріоритет у порядку зменшення (від найвищого до найнижчого):

1. `*` (множення)
2. `+`, `-` (додавання, віднімання)
3. `=`, `>` (операції порівняння)
4. `¬` / `not` (заперечення)
5. `∨` / `or` (диз’юнкція)
6. `:=` (присвоєння)
7. `while ... do ...` (цикл)
8. `if ... then ... else ...` (умовний оператор)
9. `;` (послідовне виконання)

Через те, що `;` має нижчий пріоритет за `while` та `if`, складене тіло циклу чи гілки умови групується через `begin ... end`.
